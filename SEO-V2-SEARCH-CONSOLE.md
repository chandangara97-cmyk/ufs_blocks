# Luxotic India SEO V2

This release is optimized around the 31 Aug 2026 Search Console export.

## Actual search opportunities used
- tourist places in Himachal Pradesh with map
- map of Himachal Pradesh tourist places
- Himachal Pradesh tourist spot map
- best time to visit Mandi
- Chamba district
- Kinnaur Valley map
- tracks in Himachal
- Spiti height in feet
- where is Spiti
- Mandi travel agency

## Key technical changes
- Canonical metadata standardized on public pages.
- Destination pages strengthened with visible travel-planning sections.
- Explore page targets map-related queries.
- Packages page targets tour-package queries.
- Static package pages receive canonical, OG/Twitter and breadcrumb metadata.
- Dynamic package-detail.html is noindex to avoid duplicate competition with static package URLs.
- Sitemap rebuilt with canonical public URLs and static package pages.
- Admin/internal pages removed from the sitemap and selected utilities blocked in robots.txt.

## Important
SEO changes cannot guarantee rankings. Submit the updated sitemap in Google Search Console and request indexing for the highest-priority destination/package pages.
